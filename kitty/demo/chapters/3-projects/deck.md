Getting around projects
=======================

You're working on several projects
at once, each with its own shells and
Claude Code sessions, all in one
kitty window.

Every key here is real: watch the
badge at the bottom.

<!-- end_slide -->

<!-- jump_to_middle -->

The setup: a tab per project
============================

<!-- incremental_lists: true -->

* slides: this deck
* shop-api: Claude Code adding rate
  limiting, plus a shell
* infra: Claude Code moving
  Terraform state
* docs: two shells, untouched for weeks
* scratch: shop-api's dev server,
  left running in the wrong tab

Let's look: ⌃⇥, tab by tab.

<!-- end_slide -->

<!-- jump_to_middle -->

Four ways around
================

<!-- incremental_lists: true -->

* ⌘§ jump to a project
* ⌥⇥ find any window, Claude
  sessions by their title
* ⇧⌘W tidy up
* ⌘I / ⌘B the project's IDE
  or web page

<!-- end_slide -->

<!-- jump_to_middle -->

Jump to a project: ⌘§
========================

<!-- incremental_lists: true -->

* Open projects first, then the rest,
  by how often you go there
* Type to filter, ↩ to jump
* Watch: ⌘§, "shop", ↩

<!-- end_slide -->

<!-- jump_to_middle -->

Every window, live: ⌥⇥
==============================

<!-- incremental_lists: true -->

* Claude Code panes show their
  conversation title
* Type to filter: titles count too
* The preview is the live screen
* ⎋ leaves you where you were
* Watch: ⌥⇥, then type "rate"

<!-- end_slide -->

<!-- jump_to_middle -->

Tidy up: ⇧⌘W
====================

<!-- incremental_lists: true -->

* Claude reviews every window
* Stale ones: close
* Strays: back to their project's tab
* ↩ applies; ⇥ unticks one
* Watch: ⇧⌘W, then ↩

<!-- end_slide -->

<!-- jump_to_middle -->

After the tidy-up
=================

<!-- incremental_lists: true -->

* shop-api's dev server is back in
  the shop-api tab, still running
* docs is down to one shell, or gone
* Watch: ⌃⇥, tab by tab

<!-- end_slide -->

<!-- jump_to_middle -->

A project with no window
========================

<!-- incremental_lists: true -->

* ⌘§, pick it, ↩
* A shell opens there, beside you
* Watch: ⌘§, "blog", ↩

<!-- end_slide -->

<!-- jump_to_middle -->

Open the IDE: ⌘I
===================

<!-- incremental_lists: true -->

* VS Code or IntelliJ, on the
  project you're in
* Watch: ⌘I on the blog pane

<!-- end_slide -->

<!-- jump_to_middle -->

The project's web page: ⌘B
=============================

<!-- incremental_lists: true -->

* Its GitHub or GitLab page
* An open tab is reused
* Watch: ⌘B on the blog pane

<!-- end_slide -->
