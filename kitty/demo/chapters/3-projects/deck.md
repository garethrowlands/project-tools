Getting around projects
=======================

You're working on several projects
at once, each with its own shells and
Claude Code sessions, all in one
kitty window.

Every key here is real: watch the
badge at the bottom.

<!-- end_slide -->

<!-- jump_to_middle -->

The setup: a tab per project
============================

<!-- incremental_lists: true -->

* web-app: these slides
* shop-api: Claude Code adding rate
  limiting, plus a shell
* infra: Claude Code moving
  Terraform state
* docs: a git log left open weeks ago
* scratch: a stray shop-api shell

Let's look: Ctrl+Tab, tab by tab.

<!-- end_slide -->

<!-- jump_to_middle -->

Four ways around
================

<!-- incremental_lists: true -->

* Cmd+§ jump to a project
* Option+Tab find any window, Claude
  sessions by their title
* Cmd+Shift+W tidy up
* Cmd+I / Cmd+B the project's IDE
  or web page

<!-- end_slide -->

<!-- jump_to_middle -->

Jump to a project: Cmd+§
========================

<!-- incremental_lists: true -->

* Open projects first, then the rest,
  by how often you go there
* Type to filter, Enter to jump
* Ctrl+Shift+Tab comes back

<!-- end_slide -->

<!-- jump_to_middle -->

Every window, live: Option+Tab
==============================

<!-- incremental_lists: true -->

* Claude Code panes show their
  conversation title
* Type to filter: titles count too
* The preview is the live screen
* Esc leaves you where you were

<!-- end_slide -->

<!-- jump_to_middle -->

Tidy up: Cmd+Shift+W
====================

<!-- incremental_lists: true -->

* Claude reviews every window
* Stale ones: close
* Strays: back to their project's tab
* Enter applies; Tab unticks one

<!-- end_slide -->

<!-- jump_to_middle -->

A project with no window
========================

<!-- incremental_lists: true -->

* Cmd+§, pick it, Enter
* A shell opens there, beside you

<!-- end_slide -->

<!-- jump_to_middle -->

Open the IDE: Cmd+I
===================

<!-- incremental_lists: true -->

* VS Code or IntelliJ, on the
  project you're in

<!-- end_slide -->

<!-- jump_to_middle -->

The project's web page: Cmd+B
=============================

<!-- incremental_lists: true -->

* Its GitHub or GitLab page
* An open tab is reused

<!-- end_slide -->

<!-- jump_to_middle -->

That's getting around
=====================

<!-- incremental_lists: true -->

* Cmd+§ jump to a project
* Option+Tab every window
* Cmd+Shift+W tidy up
* Cmd+I the IDE
* Cmd+B the web page
